01

관람객 가이드

별도의 설치나 앱 없이, 링크 하나로 3D 전시장에 입장할 수 있습니다. 우물반자(코퍼) 천장 아래 지하 미디어관부터 옥상 테라스까지 4개 층으로 이어지는 미술관 공간을 1인칭 시점으로 자유롭게 걸어다니며 작품을 감상하세요.

입장하기

전시장 링크에 접속하면 가장 먼저 로비 화면이 나타납니다.

  1. 닉네임을 입력하세요. 비워두면 자동으로 게스트로 입장합니다.
  2. 마스코트 캐릭터 아야모를 눌러 헤어·표정·의상을 꾸며보세요. 꾸민 모습은 저장되어 다음 방문에도 유지됩니다.
  3. 입장하기 버튼을 누르면 전시장으로 들어갑니다. 이때 새소리·바람 소리 같은 배경음이 함께 재생됩니다. (브라우저 자동재생 정책상 버튼을 누른 뒤에만 소리가 시작됩니다.)

PC 조작법

키보드와 마우스로 자유롭게 이동하며 관람할 수 있습니다. 전시장 화면을 한 번 클릭하면 마우스 커서가 화면에 고정되고, 이후 마우스를 움직이는 대로 시점이 회전합니다. Esc를 누르면 커서 고정이 풀립니다.

조작동작
마우스 이동시점 회전 (화면을 클릭해 커서를 고정한 뒤)
WASD이동 (앞·왼쪽·뒤·오른쪽)
Shift달리기 (이동 중 함께 누르기)
E작품 3m 이내 접근 시, 라이트박스(전체화면 확대)로 감상
Enter채팅 입력창 열기 / 메시지 전송
P사진 촬영 — 현재 화면을 캡처해 SNS로 공유
Esc라이트박스 닫기 · 채팅 입력 취소 · 마우스 커서 고정 해제

모바일 조작법

스마트폰·태블릿에서는 화면을 터치하여 조작합니다. 별도의 설정 없이 화면을 반으로 나누어 인식합니다.

화면 왼쪽

터치한 채로 드래그하면 그 방향으로 이동합니다. 손을 떼면 멈춥니다.

화면 오른쪽

터치한 채로 드래그하면 시점(카메라)이 회전합니다.

작품에 가까이 다가가면 화면에 나타나는 정보 패널의 안내에 따라 확대 감상할 수 있습니다.

작품 감상하기

작품에 3m 이내로 가까이 다가가면 화면 우측에 작가·제목·설명이 담긴 정보 패널이 나타납니다.

  • PC에서는 E 키를 눌러 라이트박스(전체화면 확대 보기)를 엽니다.
  • 라이트박스는 Esc 키, 우측 상단의 × 버튼, 또는 어두운 배경 클릭으로 닫을 수 있습니다.
  • 라이트박스가 열려 있는 동안에는 이동·채팅 등 다른 조작이 일시적으로 멈춥니다.

채팅

같은 전시장에 접속한 다른 관람객은 각자의 색상 아바타로 실시간으로 보입니다. Enter 키를 누르면 채팅창이 활성화되며, 메시지를 입력하고 다시 Enter를 눌러 전송합니다. Esc로 입력을 취소할 수 있습니다.

전시 선택하기

로비 화면의 전시 선택 목록에서 원하는 전시를 골라 입장할 수 있습니다. 특정 전시로 곧바로 이동하려면 주소 끝에 ?g=<전시id>를 붙인 링크를 사용하세요.

02

작가 가이드

작가 스튜디오에서는 회원가입이나 서버 업로드 없이, 브라우저 안에서 작품 정보를 입력하는 것만으로 나만의 3D 전시장을 만들고 바로 공유할 수 있습니다.

스튜디오 열기

상단 메뉴 또는 랜딩 페이지의 작가 스튜디오 링크로 이동하면 전시 정보 입력 화면이 나타납니다.

전시 정보 입력

  • 전시 ID — 전시를 구분하는 짧은 영문 식별자입니다. (예: syhongart)
  • 전시 제목 — 전시장 안에서 표시될 이름입니다.
  • 소개 — 전시에 대한 설명 문구입니다.

작품 추가하기

작품은 최대 14점까지 등록할 수 있습니다. 각 작품마다 제목, 작가명, 연도, 설명과 함께 이미지 URL을 입력합니다.

이미지 URL 준비 팁 — 파일을 직접 업로드하지 않고, 웹에 이미 공개되어 있는 이미지 주소를 사용합니다. 권장 해상도는 1200px 이상이며, 가로세로 비율은 어떤 형태든 상관없습니다. URL을 입력하면 바로 옆에 미리보기가 표시되어 확인할 수 있습니다.

대표작 지정

등록한 작품 중 최대 2점을 대표작(featured)으로 지정할 수 있습니다. 대표작은 전시장 중앙 가벽 정면에 걸려, 입장하는 관람객이 가장 먼저 마주하는 위치에 배치됩니다.

미리보기 & 공개

정보 입력이 끝나면 세 가지 방법으로 전시를 확인하고 공개할 수 있습니다.

내 전시 미리보기

지금 입력한 내용 그대로 3D 전시장을 즉시 열어 확인합니다. 저장이나 공유 전, 배치를 점검하는 용도입니다.

공유 링크 만들기

  • 전시 데이터가 URL 자체에 담깁니다.
  • 서버 업로드 없이 링크만 전달하면 누구나 바로 관람 가능합니다.
  • 작품 수·설명이 많으면 링크가 길어질 수 있습니다.

JSON 다운로드

  • 전시 데이터를 파일(.json)로 저장합니다.
  • 정식으로 전시 목록(galleries)에 등재하기 위한 방식입니다.
  • 다운로드한 파일을 현재 운영자에게 전달하면 등록됩니다.

임시저장

스튜디오에서 작성 중인 내용은 브라우저에 자동으로 임시저장됩니다. 창을 닫았다가 같은 브라우저로 다시 열어도 입력하던 내용이 유지됩니다. (단, 브라우저 저장 공간을 초기화하거나 다른 브라우저·기기로 접속하면 남아있지 않으니, 최종본은 JSON 다운로드로 보관해 두는 것을 권장합니다.)

03

블렌더로 나만의 전시장 건물 만들기

기본으로 제공되는 미술관 대신, 블렌더(Blender)로 직접 설계한 건물 안에서 전시를 열 수도 있습니다. 처음 다뤄보는 분도 아래 순서를 따라가면 어렵지 않게 준비할 수 있습니다.

개요

ARTSHOW는 기본으로 제공하는 미술관 공간 외에도, 작가가 블렌더로 직접 만든 전시장 건물 파일(.glb)을 올려 자기만의 공간에서 전시를 열 수 있습니다. 현재는 준비 중인 기능으로, 완성한 파일을 운영자에게 전달하는 방식으로 시작합니다.

첫 파일이 완벽할 필요는 없습니다. 회색 박스로 벽·바닥·계단의 큰 덩어리만 잡은 매스 모델을 먼저 보내주셔도 괜찮습니다. 시스템에 한 번 연결한 뒤에는, 디테일을 채운 파일로 교체해가며 반복해서 다듬을 수 있습니다.

파일 포맷

  • glTF 2.0 바이너리(.glb) 단일 파일로 내보냅니다. 블렌더 상단 메뉴의 File → Export → glTF 2.0을 사용하세요.
  • FBX·OBJ 파일은 사용할 수 없습니다. 재질 정보가 손실되고, 웹 표준 포맷이 아니기 때문입니다.
  • 텍스처 이미지는 별도로 첨부할 필요 없이 .glb 파일 안에 자동으로 내장됩니다.

스케일과 좌표

전시장은 실제 사람 크기를 기준으로 한 실측 스케일로 동작합니다. 아래 사항을 지켜야 전시장에 들어갔을 때 크기와 방향이 의도한 대로 반영됩니다.

  1. 1 블렌더 유닛 = 1미터로 작업합니다. 문 높이는 약 2.1m, 층고는 3~4m를 권장합니다.
  2. 건물의 중심을 월드 원점 근처에 두고 모델링합니다.
  3. 내보내기 전, 모든 오브젝트를 선택한 뒤 CtrlA → All Transforms를 적용해 스케일·회전 값을 정리합니다. 이 과정을 빼먹으면 크기가 틀어질 수 있습니다.
  4. 위쪽 축은 블렌더 기본값인 Z-up 그대로 작업하면 됩니다. 익스포터가 자동으로 변환해 줍니다.

이름 규칙

가장 중요한 규칙입니다. 오브젝트 이름을 통해 각 요소의 기능이 시스템에 연결되므로, 아래 표의 이름 규칙을 정확히 지켜야 합니다.

이름종류역할
FLOOR_메시걸을 수 있는 바닥·계단·경사로입니다. 계단도 실제 메시로 만들어 두면 그대로 걸어 올라갈 수 있습니다.
WALL_메시통과할 수 없는 벽·난간·유리입니다. 보이지 않는 단순한 형태의 충돌 박스를 따로 만들어 붙이는 방식을 권장합니다 (성능에 유리합니다).
AW_01 ~ AW_14Empty작품이 걸릴 자리입니다. 벽 앞에 Empty(빈 오브젝트)를 두고 -Y축이 관람자 쪽을 향하도록 회전하면, 그 자리에 액자·조명·작품 설명 플라크가 자동으로 생성됩니다.
AW_F1, AW_F2Empty대표작이 걸릴 자리 2개입니다. 다른 작품보다 크게 걸립니다. 배치 방법은 AW_01~AW_14와 동일합니다.
SPAWNEmpty관람객이 입장하는 위치입니다. 1개만 두고, 바라보았으면 하는 방향으로 회전해 둡니다.
LAMP_Empty (선택)조명을 놓을 위치입니다. 두면 그 자리에 포인트 조명이 생성되고, 두지 않으면 기본 조명 시스템이 사용됩니다.
LEAF_메시알파 컷아웃으로 표현하는 잎·식물류 메시입니다. 그림자 처리가 자동으로 보정됩니다.
GLASS_재질 이름재질(머티리얼) 이름에 붙이면 유리로 인식되어 투명 보정이 적용됩니다.

재질과 텍스처

  • 재질은 Principled BSDF 노드만 사용합니다. 다른 방식으로 조합한 셰이더 노드는 내보내기 시 반영되지 않습니다.
  • 텍스처 해상도는 1024~2048px를 권장합니다. 면적이 넓은 벽은 하나의 텍스처를 확대하기보다 타일링 UV로 반복시키는 방식을 사용하세요.
하늘·태양·환경광은 모델에 넣지 마세요. 전시장의 낮·황혼·밤 등 실시간 테마 조명 시스템이 이를 대신 담당합니다.

알파(투명) 텍스처

알파(투명) 텍스처는 완전히 지원됩니다. 알파 채널이 있는 텍스처는 PNG를 사용하세요 (JPG는 알파 채널을 담을 수 없습니다). 셰이더에서는 Image Texture 노드의 Alpha 출력을 Principled BSDF의 Alpha 입력에 연결합니다.

Material Properties → Settings → Blend Mode에서 아래 두 가지 중 상황에 맞게 선택합니다.

Alpha Clip

나뭇잎, 철망, 레이스, 스텐실 등에 사용합니다. 앞뒤 정렬 문제가 없고 가볍습니다. 특별한 이유가 없다면 웬만하면 이 방식을 사용하세요.

Alpha Blend

반투명 유리, 시스루 커튼처럼 부드러운 반투명 표현에 사용합니다. 반투명한 것끼리 겹치면 앞뒤 순서가 튈 수 있으므로, 꼭 필요한 곳에만 제한적으로 사용하세요.

  • Clip Threshold는 보통 0.5로 두면 됩니다. 뒷면도 보여야 하는 오브젝트라면 Backface Culling을 해제하세요.
  • 작품 이미지 자체도 투명 PNG를 지원합니다. 이미지의 투명한 영역은 액자의 흰 매트지처럼 보입니다.

재질 공유

같은 콘크리트 면이라면 머티리얼 하나를 여러 오브젝트에 공유해서 씁니다. 텍스처가 중복으로 내장되는 것을 막아주는, 가장 중요한 수칙입니다.

이미지 포맷

알파(투명)가 꼭 필요한 텍스처만 PNG로, 나머지는 JPG로 저장합니다.

텍스처 크기

4K 크기의 유니크 텍스처 한 장보다, 1K 크기를 타일링해서 반복하는 편이 훨씬 가볍습니다.

04

자주 묻는 질문

이용 중 궁금한 점을 모았습니다.

소리가 안 나요
브라우저의 자동재생 정책 때문에 사용자의 첫 클릭(입장하기 버튼) 이후에만 소리가 재생됩니다. 로비에서 입장하기 버튼을 눌러 들어왔는지 확인하고, 기기·브라우저의 음소거 상태와 볼륨도 함께 확인해 주세요.
친구가 안 보여요
같은 전시(같은 전시 ID)에 동시에 접속해 있어야 서로의 아바타가 보입니다. 네트워크 환경(회사·학교 방화벽, VPN 등)에 따라 실시간 연결이 원활하지 않을 수 있으니, 다른 네트워크에서 다시 시도해 보세요.
모바일에서도 되나요
네, 별도 앱 설치 없이 모바일 브라우저에서 바로 관람할 수 있습니다. 화면 왼쪽을 터치·드래그하면 이동, 오른쪽을 터치·드래그하면 시점이 회전합니다.
공유 링크가 너무 길어요
공유 링크는 전시 데이터를 주소 안에 그대로 담기 때문에, 작품 수가 많거나 설명이 길면 주소도 함께 길어집니다. 설명 문구를 간결하게 줄이거나, 정식 등록이 필요하다면 JSON 다운로드 방식을 이용해 주세요.
작품 이미지가 안 나와요
입력한 이미지 URL이 웹에서 실제로 열람 가능한 공개 주소인지 확인해 주세요. 비공개 저장소·로그인이 필요한 페이지·만료된 링크는 표시되지 않습니다. 스튜디오의 미리보기에서 이미지가 보이면 전시장에서도 정상적으로 표시됩니다.
지원 브라우저는 무엇인가요
최신 버전의 Chrome, Edge, Safari, Firefox 등 WebGL을 지원하는 브라우저에서 이용할 수 있습니다. 가급적 최신 버전으로 업데이트한 뒤 이용해 주세요.
전시를 나중에 수정할 수 있나요
스튜디오에서 다시 작품 정보를 입력한 뒤 새로 공유 링크를 만들거나 JSON을 다시 내려받아 전달하면 됩니다. 브라우저에 임시저장된 내용이 남아있다면 이어서 수정할 수 있습니다.
SNS에 어떻게 공유하나요
전시장 안에서 P를 누르거나 모바일 하단 독의 캡처 버튼을 누르면 현재 화면이 사진으로 저장되고 공유 창이 열립니다. 여기서 기기로 바로 공유하거나, 이미지를 저장하거나, X·Threads에 바로 게시할 수 있습니다. 인스타그램은 별도 공유 인텐트가 없으니 이미지를 저장하거나 기기로 공유한 뒤 앱에서 직접 올려주세요.
