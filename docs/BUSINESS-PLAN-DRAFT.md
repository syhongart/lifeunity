# OpenArtShow 사업계획서 초안 (예비창업패키지 대비)

> 2027년 초 예비창업패키지 공고 대비 PSST 표준 구조 초안.
> 공고 확정 시 해당 연도 양식·분량 기준으로 재편집한다.
> 상태: v0.1 (2026-07-12) — 감독 검토 전.

## 한 줄 소개

**링크 하나로 열리는 나만의 3D 미술관** — 설치도 가입도 필요 없이
브라우저에서 바로 작품 사이를 거니는, 작가 1인당 1갤러리 웹 전시 플랫폼.

---

## 1. Problem (문제 인식)

### 1-1. 창업 아이템의 필요성

- 작가가 개인전을 열려면 대관료 수백만 원 + 운송·설치 + 2주 남짓의
  전시 기간. 전시가 끝나면 공간도 기록도 사라진다.
- 온라인 대안은 양극단뿐이다. ① 인스타그램/포트폴리오 사이트 —
  이미지 나열이라 "전시"의 공간 경험이 없음. ② 기존 VR 전시 툴 —
  앱 설치·회원가입·고사양 요구로 관람객이 문 앞에서 이탈.
- 관람객 쪽 마찰이 본질: 링크를 눌러서 3초 안에 입장되지 않으면
  공유가 일어나지 않는다.

### 1-2. 창업자가 이 문제를 아는 이유

- 창업자 본인이 활동 중인 시각예술가(예술활동증명 보유)로서 위
  비용·소멸성 문제를 직접 겪음. 예술가가 예술가를 위해 만드는 도구.

## 2. Solution (실현 가능성)

### 2-1. 제품 현황 — 아이디어가 아니라 작동하는 서비스

- **이미 배포·작동 중** (GitHub Pages, 서버 비용 0원 구조):
  - 노빌드 웹 3D(Three.js): 설치·가입 없이 URL 입장, 모바일 60fps
  - 멀티플레이(P2P): 친구와 같은 갤러리를 함께 관람, 채팅·리액션
  - 갤러리당 다층 전시 공간, 시간대가 흐르는 하늘(HDRI), 방명록·사진
  - 자체 마스코트 캐릭터 "아야모"(법적 검증 완료, 자체 IP)
  - 저사양 PC 자가 진단·자동 최적화(포테이토 모드) — 접근성 극대화
- **핵심 원칙: 1계정 = 1갤러리** (운영원칙 문서 보유). 작가의
  정체성 공간이라는 포지션 — SNS 피드가 아니라 "내 미술관".

### 2-2. 차별화 — AI 관람객 (로드맵 보유)

- AI 에이전트가 갤러리를 방문·관람·평을 남기는 개방 규격
  (llms.txt / MCP 커넥터) 로드맵 확보. "빈 갤러리" 콜드스타트 문제를
  AI 관객으로 해소 — 작가는 첫날부터 피드백을 받는다.
- 경쟁 서비스(해외 VR 전시 툴)에 없는 포지션: "AI도 관람하는 미술관".

### 2-3. 기술 실현 가능성

- 전 기능이 표준 웹 기술로 구현되어 앱 심사·설치 장벽 없음.
- 정적 호스팅 + P2P 구조로 초기 운영비 ≈ 0 → 지원금은 전액
  기능 개발·디자인·마케팅에 투입 가능.

## 3. Scale-up (성장 전략)

### 3-1. 수익 모델 (단계형)

1. **프리미엄 구독**: 기본 갤러리 무료 → 확장 공간·커스텀 건물
   (블렌더 파이프라인 규격 보유)·프리미엄 테마 유료
2. **B2B/기관**: 갤러리·아트페어·학교 졸업전시의 온라인 상설관
3. **(장기, 법무 검토 후) 작품 연계**: 원작 판매 링크 중개 —
   수수료 모델. 내부 보상은 폐쇄형 포인트(법무 사전검토 완료)로
   금융 규제 비적용 구조 유지

### 3-2. 시장

- 국내 등록 예술활동증명 예술인 15만+ (1차 시장: 개인 작가),
  졸업전시·공모전·아트페어의 디지털 상설화 수요 (2차: 기관).
- 글로벌 확장 전제 설계: 서비스명·마스코트명 글로벌 기준으로
  선정 완료, 웹 기반이라 국경 없는 배포.

### 3-3. 자금 소요·조달 (예창패 사업화 자금 기준)

- 외주개발(백엔드: 계정·방명록 영속화·결제) / 디자인(브랜드·
  공간 에셋) / 마케팅(작가 커뮤니티·아트페어 제휴) / 인증·법무
- 구체 배분은 공고 연도 기준 상한에 맞춰 산정.

### 3-4. 로드맵 (신청 시점까지의 트랙션 계획)

- 2026 H2: 초기 작가 갤러리 유치(목표 수치 기입), AI 관람 데모
  공개, 서울문화재단/ARKO 공모("온라인 3D 기획전" 서사) 병행
- 2027 H1: 예창패 선정 → 사업자등록 → 계정·결제 실装, 유료 전환
- 2027 H2: KOCCA·아트코리아랩 초기창업(후속 지원) 연계

## 4. Team (팀 구성)

- 창업자: 시각예술가 겸 감독 — 도메인 당사자 + 제품 총괄.
  기획·디자인·개발 전 과정을 AI 협업 체계로 1인 수행 중
  (개발일지·운영원칙·법무 검토 절차 문서화 운영).
- 선정 후: 외주 파트너(백엔드·디자인) + 자문(법무·회계) 구성.
