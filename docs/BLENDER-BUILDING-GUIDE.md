# ARTSHOW 커스텀 건물 제작 규약 (Blender → GLB)

블렌더로 모델링한 건물을 ARTSHOW 전시장으로 불러오기 위한 제작·명명·내보내기 규약.
**충돌(컬리전)과 조명(베이킹) 모두 블렌더에서 완성**해서 내보낸다 — 엔진은 계산하지
않고 "읽기만" 한다. 이 규약대로 만든 GLB는 임포터가 자동으로 해석한다.

---

## 0. 한눈에 보기

| 이름 | 종류 | 필수 | 역할 |
|---|---|---|---|
| `spawn` | Empty | ✅ | 입장 위치 + 처음 바라보는 방향 |
| `slot_01` … `slot_99` | Empty | ✅ 1개 이상 | 작품이 걸리는 자리 (벽면) |
| `tour_01` … `tour_99` | Empty | 권장 | 도슨트 투어 경유지 (번호 순서대로 이동) |
| `col_…` | Mesh | ✅ | 충돌 전용 메시 (벽·난간 — 화면에 안 보임) |
| `floor_…` | Mesh | ✅ | 걸을 수 있는 바닥 (지면 높이 판정용) |
| 그 외 메시 | Mesh | — | 보이는 건물 본체 (충돌 없음, 이름 자유) |

- 단위: **1 Blender 유닛 = 1 m** (Scene Properties → Units → Metric)
- 원점: 입구 앞 바닥 높이 = Z(높이) 0
- 파일: **.glb 단일 파일** (텍스처 포함), 압축(Draco) 사용 금지

---

## 1. 보이는 메시 (건물 본체)

- 이름 자유. 눈에 보이는 모든 것 — 벽, 천장, 바닥 마감, 기둥, 몰딩, 소품.
- **예산**: 전체 삼각형 10만 개 이하, 텍스처 한 장 최대 2048×2048,
  GLB 총 용량 15 MB 이하 (모바일 로딩 한계).
- 머티리얼은 Principled BSDF만 사용 (glTF가 온전히 내보내는 유일한 셰이더).

## 2. 충돌 메시 — `col_` 접두사

- 플레이어가 **뚫고 갈 수 없는 곳** 전부를 아주 단순한 박스/플레인으로 감싼다:
  외벽, 실내 칸막이, 난간, 유리, 큰 가구.
- 이름을 `col_`로 시작 (`col_outerwall`, `col_rail_2f` …).
- 임포터가 화면에서 숨기고 충돌 판정에만 쓴다 — **머티리얼·UV 불필요, 최대한
  로우폴리로** (충돌 메시 전체 합계 삼각형 2,000개 이하 권장).
- 문·통로는 뚫어 둔다(충돌 메시를 안 두면 지나갈 수 있는 곳이 된다).

## 3. 바닥 메시 — `floor_` 접두사

- 플레이어가 **서고 걸을 수 있는 면**: 각 층 바닥, 계단(경사면으로 단순화 가능),
  경사로. 이름을 `floor_`로 시작 (`floor_1f`, `floor_stair_a` …).
- 위에서 내려다봤을 때 겹침 없이 깔끔하게 — 지면 높이는 이 메시에 수직
  레이캐스트로 판정한다.
- 계단은 실제 단 지오메트리 대신 **매끈한 경사 플레인 하나**를 `floor_`로 두면
  걷기가 부드럽다 (보이는 계단 메시는 본체 쪽에 따로).

## 4. Empty 마커

모두 **Empty(Plain Axes 또는 Single Arrow)** 로 만들고 정확한 이름을 붙인다.

### `spawn` (필수, 1개)
- 위치: 입장 지점의 **바닥 위** (발 위치 — 눈높이는 엔진이 더한다).
- 방향: Empty의 **로컬 -Y(블렌더에서 정면)** 가 처음 바라볼 방향.

### `slot_01` ~ (필수, 최소 1개)
- 위치: 작품 **중심점** — 벽면에서 살짝(1~2 cm) 앞, 바닥에서 약 1.5 m 높이.
- 방향: 로컬 **-Y가 방 안쪽**(관람객 쪽)을 향하게 벽에서 바깥으로.
- 번호는 01부터 연속으로. 스튜디오의 작품 순서가 이 번호 순서로 걸린다.

### `tour_01` ~ (권장)
- 위치: 관람 동선의 요점 — 눈높이가 아니라 **바닥 위 발 위치**.
- 방향: 로컬 -Y가 그 지점에서 바라볼 곳(대개 가까운 작품).
- 없으면 slot 순서로 투어를 자동 생성한다.

## 5. 조명 베이킹 (블렌더에서 완성)

엔진은 임포트한 건물에 **조명 계산을 하지 않는다**. 조명·그림자·AO는 전부
블렌더에서 텍스처로 구워 온다. 임포터가 건물 머티리얼을 **unlit(무조명)** 으로
전환하므로, 구운 그대로 화면에 나온다.

권장 절차 (Cycles):

1. 씬에 실제 광원 배치 (태양광, 천장 조명 등) — 광원 자체는 내보내지 않는다.
2. 베이크 대상 오브젝트에 **두 번째 UV 채널** 추가 → 전체 Smart UV Project
   (Island Margin 0.02) 또는 수동 아틀라스.
3. 새 이미지(2048×2048, 32-bit) 생성, 각 머티리얼 노드에 Image Texture로 추가
   후 **선택 상태**로 둔다.
4. Render Properties → Bake → Bake Type **Combined** (Direct+Indirect 체크),
   Margin 8 px → Bake.
5. 구운 이미지를 각 머티리얼의 **Base Color에 연결**(기존 텍스처와 합성했으면
   합성 결과를 다시 굽는다), 이미지 **Pack** (File → External Data → Pack).
6. 광원·베이크용 보조 노드 제거 후 내보내기.

- 그림자가 닿는 벽·바닥만 구워도 충분하다. 작은 소품은 균일 밝기로 놔둬도 된다.
- AO만이라도 굽자 — 벽-바닥 만나는 곳이 어두워지면 공간감이 산다.

## 6. 내보내기 (glTF 2.0)

File → Export → glTF 2.0:

- Format: **glTF Binary (.glb)**
- Include: Selected Objects 해제 (전체), **Custom Properties 체크**
- Transform: +Y Up (기본값)
- Data → Mesh: Apply Modifiers 체크
- Data → Material: Images **Automatic**, 압축 옵션 전부 해제 (Draco 금지)

내보내기 전 체크리스트:

- [ ] 모든 Transform Apply (Ctrl+A → All Transforms)
- [ ] `spawn` 1개, `slot_` 1개 이상 존재
- [ ] `col_` 메시가 외곽을 빈틈없이 두르는지 (구멍 = 탈출 버그)
- [ ] `floor_` 메시가 모든 보행 구역을 덮는지
- [ ] 텍스처 Pack 완료 (외부 파일 참조 없음)
- [ ] 파일 15 MB 이하

## 7. 자주 하는 실수

| 증상 | 원인 |
|---|---|
| 입장하자마자 추락 | `spawn` 밑에 `floor_` 메시가 없음 |
| 벽을 뚫고 나감 | `col_` 메시 이음새 틈 (모서리 겹치게 두껍게) |
| 작품이 벽 속에 파묻힘 | `slot_` Empty가 벽면 뒤에 있거나 -Y가 벽 쪽을 향함 |
| 건물이 새까맣거나 새하얌 | 베이크 이미지를 Base Color에 연결 안 함 / Pack 안 함 |
| 로딩이 몇십 초 | 텍스처 4K 다수, 15 MB 초과 — 2K 이하로 리사이즈 |
