## 상표 출원 절차 (아야모 · ARTSHOW) — 리서치 완료 2026-07-13

> 핵심 결론: **아야모(Ayamo)는 조어라 셀프 출원 무난. ARTSHOW는 'art show=
> 미술전시'라 식별력 거절 위험 → 출원 전 변리사 무료상담 권고.** 상표는
> "지정한 류(class)에서만" 보호되고, "출원한 형태 그대로" 보호된다.

### 1단계 — 선행상표 검색 (무료, KIPRIS)
- [ ] [kipris.or.kr](https://www.kipris.or.kr) → [상표] 검색
- [ ] "아야모 / Ayamo / AYAMO", "ARTSHOW / 아트쇼 / ART SHOW" 각각 검색
- [ ] **행정상태를 '전체'로** (등록 + 출원중까지 봐야 선점 판단 정확)
- [ ] 아래 정할 류(41·42류)로 필터 — 유사판단은 같은 류 안에서만

### 2단계 — 지정 류(니스 분류) 정하기
- **41류(온라인 전시·엔터)** = 우리 사업 핵심 (3D 미술관·작가 전시) ← 필수
- **42류(SaaS·SW개발)** = 플랫폼 클라우드 제공 ← 필수
- (선택) 9류(다운로드 앱), 35류(작품 판매 중개·마켓) — 그 수익모델 생기면
- [ ] 예산 빠듯하면 **41+42 두 류**로 시작

### 3단계 — 아야모 셀프 출원 (특허로)
- [ ] [patent.go.kr](https://www.patent.go.kr) → **특허고객번호 발급**(최초 1회, 무료)
- [ ] 공동/금융 인증서 등록 + 출원서 작성 프로그램 설치
- [ ] 상표등록출원서: **문자상표(아야모/Ayamo) 1건** + **도형상표(아야모
  캐릭터 그림) 1건 별도** — 별도 출원이 보호범위 가장 넓음(이름·그림 각각 방어)
- [ ] 지정상품은 **특허청 '고시명칭'으로 선택**(자기 말로 적으면 +6,000원·지연)
- [ ] 출원료 납부

### 4단계 — ARTSHOW는 먼저 변리사 무료상담
- [ ] 'art show'는 미술전시 기술적 표장이라 41류에서 **거절 위험 실재**
- [ ] 변리사 무료검토로 등록 가능성 확인 → 로고 결합/‘아야모’ 앞세운 결합
  ('ARTSHOW by Ayamo' 등)으로 식별력 보강 전략 상담 후 결정

### 💰 비용 (2025-26 현행, 개인 전자출원 · 류당)
| 항목 | 금액 | 시점 |
|---|---|---|
| 출원료(전자) | **46,000원/류** | 출원 시 (고시명칭 10개 이내) |
| 설정등록료 | **201,000원/류** | **등록결정 후에만** (거절 시 안 냄) |
| 우선심사(선택) | 160,000원/류 | 2~3개월로 단축(일반 ~15개월) |

- 아야모 문자+도형, 각 41+42류, 등록까지 총 **약 99만원**(2류 기준).
  1개 류만 하면 절반(~49만원). **출원 단계 현금은 출원료뿐** — 등록료는 나중.

### ⚠️ 함정 (놓치기 쉬움)
- 42류만 내고 41류(전시) 빠뜨리면 사업 핵심이 보호 안 됨 → **41 먼저**
- 우선심사·대응 대비 **사용 증빙(홈페이지·사업계획) 미리 확보**
- 등록결정 후 **등록료 납부기한 놓치면 등록 무효**
